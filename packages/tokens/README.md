# @ufba-app/tokens

Tokens de design do ufba.app: cor, tipografia, raio, borda e espaçamento. Fonte única para o `web` e o `mobile`.

| Import | Conteúdo |
|---|---|
| `@ufba-app/tokens` | Valores tipados em TypeScript (`color`, `font`, `fontSize`, `radius`, `space`...) e `contrastRatio`. |
| `@ufba-app/tokens/tokens.css` | Variáveis CSS `--ufba-*` num bloco `:root`. |
| `@ufba-app/tokens/tokens.json` | Os mesmos valores em JSON, para o HeroUI Native. |

Os valores e as regras de uso estão na [especificação](../../docs/specs/2026-11-11-design-system-design.md).
