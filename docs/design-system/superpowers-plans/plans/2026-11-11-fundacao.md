# Fundação do Design System: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deixar o repositório `ufba-app/design-system` publicando `@ufba-app/tokens` e `@ufba-app/web-ui` com o tema do HeroUI v3 aplicado e os componentes da seção 4.1 da especificação.

**Architecture:** Monorepo pnpm com dois pacotes. `tokens` guarda os valores em TypeScript e gera `tokens.css` e `tokens.json`. `web-ui` importa os tokens, mapeia-os para as variáveis do HeroUI v3, sobrescreve as classes BEM do HeroUI e exporta wrappers finos de `Button` e `Chip` mais reexportações dos demais componentes.

**Tech Stack:** pnpm workspaces, TypeScript 5, tsup, Vitest + Testing Library + jsdom, vitest-axe, ESLint (flat config), Changesets, GitHub Actions, React 19, `@heroui/react` e `@heroui/styles` v3, Tailwind CSS v4.

**Spec:** `docs/specs/2026-11-11-design-system-design.md`

Este é o primeiro de vários planos. Os componentes próprios da seção 4.2 vêm em planos seguintes, um por grupo, na ordem da seção 8 da especificação.

## Global Constraints

- Nenhuma interface de catálogo (sem Storybook, sem app de demonstração).
- Nenhuma sombra em nenhum componente; borda sempre 1px na cor `border`.
- `--radius: 20px`; selos e pílulas totalmente redondos.
- Cores exatas: background `#ffffff`, foreground e accent `#1b2a7a`, accent-foreground `#ffffff`, highlight `#ffc93c`, highlight-foreground `#1b2a7a`, muted `#4d5680`, surface-soft `#eef1fb`, border `#dfe3f0`, success `#146c43` / `#e3f6ec`, danger `#b3261e` / `#fde8e6`.
- O amarelo nunca é cor de texto. O vermelho só em erro.
- Fontes: Sora (600, 800) para título e número; Plus Jakarta Sans (500, 700, 800) para texto. O pacote declara as famílias com fallback; não carrega arquivos de fonte.
- Escala de tipo (px): 12, 13, 14, 15, 19, 24, 32, 36, 76.
- Alvo de toque mínimo 44px; foco visível com contorno de 2px na cor accent e afastamento de 2px.
- Contraste mínimo de 4,5:1 para todo par texto/fundo listado nos tokens.
- `@heroui/react` e `@heroui/styles` fixados na mesma versão exata; React 19 como peer (`>=19 <20`).
- Commits no formato `tipo(escopo): descrição`; toda mudança chega à `main` por PR.

## Review Focus

1. **App Next.js com App Router importando o pacote:** os wrappers precisam funcionar como Client Components. Esperado: `dist/index.js` começa com `"use client"`. Teste na Task 3.
2. **Fontes ausentes no app consumidor:** sem Sora carregada, títulos não podem cair na fonte serifada padrão. Esperado: as variáveis de fonte trazem uma pilha de fallback sem serifa. Teste na Task 1.
3. **Ordem de importação do CSS:** o app importa `@ufba-app/web-ui/styles.css` uma vez e recebe tokens, HeroUI e sobrescritas na ordem certa. Esperado: o arquivo importa tokens antes de `@heroui/styles` e as sobrescritas ficam em `@layer components`. Teste na Task 2.
4. **Atualização do HeroUI que renomeia classes BEM:** sobrescritas silenciosamente deixariam de pegar. Esperado: o teste falha se `.button--primary`, `.chip--soft` ou `.card` não aparecerem nos elementos renderizados. Teste na Task 3.
5. **Dois formatos de token divergindo:** o mobile lê o JSON e o web lê o CSS. Esperado: um teste compara os dois arquivos gerados com a fonte em TypeScript. Teste na Task 1.

**Interfaces:**
- Consumes: classes de `components.css` da Task 2.
- Produces:
  - `Button(props: Omit<HeroButtonProps, 'variant'> & { variant?: 'primary' | 'outline' | 'highlight' | 'ghost' | 'danger'; size?: 'sm' | 'md' })`. Padrão `primary`, `md`. `highlight` vira `variant="primary"` do HeroUI mais `className="button--highlight"`; os outros passam direto.
  - `Chip(props: Omit<HeroChipProps, 'color' | 'variant'> & { tone?: 'neutral' | 'highlight' | 'success' | 'danger' | 'solid' })`. Mapeamento: `neutral` → `color="default" variant="secondary"`; `highlight` → `color="warning" variant="soft"` + `className="chip--highlight"`; `success` → `color="success" variant="soft"`; `danger` → `color="danger" variant="soft"`; `solid` → `color="accent" variant="primary"`. Padrão `neutral`.
  - Reexportados de `@heroui/react` sem mudança: `Input`, `TextField`, `Kbd`, `Tabs`, `Card`, `Avatar`, `Checkbox`, `Link`, `Tooltip`, `Modal`, `Toast`, `Skeleton`, `Separator`, `ProgressBar`.
  - `dist/index.js` com a diretiva `"use client"` na primeira linha.
